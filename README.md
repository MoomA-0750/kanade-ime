# Kanade（kanade-ime）

Samsung DeX で使うための、物理キーボード専用の Android 日本語 IME。

- 画面キーボードや余計なポップアップを出さない。物理キーボードでの入力に全振りする
- かな漢字変換は zenz（Zenzai）などのニューラル言語モデルで行い、ライブ変換を持つ
- 音声入力は Whisper 系（押している間だけ録音）と逐次認識系を切り替えて使える
- 変換・音声認識は可能な限り端末内（ローカル）で動かす

## いまできること（2026-10-03）

- ローマ字かな入力、JIS（変換・無変換など）と US（右 Alt・Ctrl+Space・F13）の日本語オン/オフ、「あ」「A」の表示
- かな漢字変換: Mozc の辞書でラティスを作り、zenz（v3.2-xsmall）で並べ替える。日常文の評価で1位の正解が辞書だけの約 75% から約 94% に
- ライブ変換、文節の区切り・伸縮・移動、候補の窓（カーソルの近く、縦並び、指で選択、説明付き）、記号・絵文字、全角/半角
- ユーザー辞書（変換で優先）、スニペット（打った瞬間に置き換え）、学習（前に選んだ候補を上に）
- F6〜F10・Ctrl+U/I/O/P/T、未確定文字列の中のカーソル移動
- 音声入力: 録音キーを押している間だけ録音。話しながら ReazonSpeech で文字を出し、離したら whisper で句読点付きの文にする（どちらも端末内）
- Termux のように未確定文字列を出せないアプリでは、入力中の文字を候補の窓に出す
- 物理キーボードがないときだけ出る画面キーボード（Unexpected Keyboard と同じ考え方。払って数字・記号、Ctrl/Alt/Fn/Esc/矢印もあり、ショートカットがそのまま使える）

主な利用端末は Galaxy Z Fold 7（Snapdragon 8 Elite、One UI 8.5 / Android 16）を DeX で使う形。
