# Kanade の使い方

物理キーボードのための日本語入力です。物理キーボードがつながっていないときは、画面キーボードで入力できます。

## はじめに

1. Kanade の設定を開くと、足りない設定があるときだけ、左の一番上に案内が出ます。案内に沿って、Kanade を入力方法として有効にし、Kanade に切り替えます
2. 「他のアプリの上に重ねて表示」を許可します。変換候補と「あ」「A」の表示を、カーソルの近くに出すのに使います（許可しないと、Galaxy で物理キーボードを使っているときに候補が出ないことがあります）
3. 音声入力を使うときは、マイクも許可します

## 日本語のオン/オフ

| キー | 動き |
|---|---|
| 変換・かな（JIS） | オン |
| 無変換・英数（JIS） | オフ |
| 半角/全角（JIS） | 切り替え |
| 右 Alt の単押し・Ctrl+Space・F13（US、設定で選びます） | 切り替え |

切り替えると、カーソルの近くに「あ」「A」が少しのあいだ出ます。

句読点（`,` と `.` で入るもの）は、設定の「入力と変換」で「、。」「，．」「、．」「，。」から選べます。

## 入力中（Space を押す前）

| キー | 動き |
|---|---|
| 文字 | ローマ字をかなにします。打つたびに変換した結果を出します（ライブ変換。設定で切れます） |
| Enter | 見えているものを確定します |
| Space・↓ | 変換を始めます（文節に分かれ、候補の窓が出ます） |
| ←→・Home・End | 入力中の文字の中でカーソルを動かします。途中にいるあいだはかなで見え、末尾に戻ると変換した結果に戻ります |
| Backspace・Delete | カーソルの前・後ろの1文字を消します |
| Shift+←→ | 変換を始めて、最初の文節を縮めます・伸ばします |
| F6〜F10・Ctrl+U/I/O/P/T | ひらがな・カタカナ・半角カナ・全角英数・半角英数にします |
| Esc | 全部取り消します |

## 変換中（Space を押したあと）

| キー | 動き |
|---|---|
| Space・↓、Shift+Space・↑ | 選んでいる文節の、次・前の候補にします |
| 1〜9 | その番号の候補を選んで、次の文節へ進みます（文節が1つなら確定します） |
| 候補を指で触る | 1〜9 と同じです。候補の窓は指でスクロールできます |
| ←→ | 文節を移ります |
| Shift+←→ | 選んでいる文節を1文字縮めます・伸ばします |
| Enter | 全体を確定します |
| 文字 | いまの変換を確定して、次の入力を始めます |
| Esc・Backspace | 変換をやめて、かなに戻ります |

候補の右には「ユーザー辞書」「ひらがな」「カタカナ」「記号」「絵文字」「全角」「半角」などの説明が出ます。
その読みの辞書の語は、すべて候補に出ます。記号（「やじるし」→「→」）や絵文字（「えがお」→「😀」）も出ます。
「きょう」「あした」「きのう」などでは日付（2026/10/03、10月3日（土）、令和8年10月3日 など）、「いま」では時刻、「ことし」「らいねん」では年も候補に出ます。

## 学習

変換で、最初に出た候補と違うものを選んで確定すると、その読みの候補として覚えます。次からは候補の上の方に出て、ライブ変換でも使われやすくなります。設定の「学習する」で切れ、「学習を消す」で覚えたものを消せます（ユーザー辞書は消えません）。

## ユーザー辞書

読み（ひらがな）と語を登録します。登録した語は変換で優先され、候補の先頭に出ます（macOS のユーザ辞書と同じです）。文の途中でも、その読みの部分に使われやすくなります。

- 設定の「ユーザー辞書」で、一覧（「追加」、行を触って編集・削除）か、テキスト（まとめて登録・コピーで書き出し）で編集します
- テキストの書式は、1行に `よみ 語` です（最初の空白で区切ります）。`#` で始まる行は無視します

```
かなで Kanade
でっくす DeX
```

## スニペット

キーを打ち終わった瞬間に、出力へ置き換えます。日本語入力中も直接入力中も使えます。

- キーは打つ文字そのものです（日本語入力中でも、かなや全角になる前の文字で見ます）
- 英字だけのキー（`sig` など）は、日本語入力中のローマ字にも反応します。記号を含むキー（`@@`、`->`）がおすすめです
- 長いキーが優先されます（`->` と `-->` があれば `-->`）
- 日本語入力中は、キーより前の入力中の文字をいま見えている形で確定してから置き換えます。直接入力中は、カーソルの前を確かめてから置き換えます（カーソルを動かしていたら置き換えません）
- テキストの書式は、1行に `キー 出力` です（最初の空白で区切ります）。出力の中の `\n` は改行です。`#` で始まる行は無視します

```
@@ you@example.com
-> →
<- ←
=> ⇒
sig お世話になっております。\nよろしくお願いいたします。
```

## 画面キーボード

物理キーボードがつながっていないときだけ、画面の下にキーボードが出ます（設定の「画面キーボード」で「いつも」「出さない」にもできます）。配列は「グライド」「フルキー」「テンキー」の3つから選べます（設定の「配列」、またはキーボードの左下のキーを上に払うと、グライド → フルキー → テンキーの順に替わります）。

押したキーは物理キーボードと同じように扱います。日本語入力・変換・F6〜F10・Ctrl+U/I/O/P/T がそのまま使え、IME で使わないキー（Ctrl+C、Ctrl+Z、端末アプリの Ctrl+D など）はアプリへそのまま送ります。高さ（300% まで）と下の余白は、設定の「画面キーボード」で変えられます（ナビゲーションバーに重なる端末では、下の余白を増やしてください）。

### フロート

キーボードを画面の下から離して、好きな位置・幅に浮かせられます（設定の「画面キーボード」の「フロート」、またはキーボードの左下のキー（?123・Ctrl・「あa1」）を下に払う）。浮かせている間はアプリの画面が縮まず、キーボードの外を触ると下のアプリを操作できます。

- キーボードの下のつまみの真ん中をドラッグすると動かせます
- つまみを勢いよく払うと、そのまま滑っていきます。画面の端に当たると少し外へはみ出して跳ね返り、端に収まります
- つまみの右端（↔）をドラッグすると幅が変わります
- つまみの左端を押すと、画面の下に戻ります
- 位置と幅は覚えておき、次に出したときも同じ所に出します

### グライド

QWERTY の文字のキーの上を、指を離さずになぞると語を入れます（Gboard のグライド入力と同じです）。文字のキーには払いの記号を置いていないので、指を動かすとすぐにグライドになります。動かさずに離せば、ふつうにその文字を打ちます。

- 日本語がオンのときは、ローマ字の綴りでなぞると、かなを入力中の文字として入れます（「arigatou」→ ありがとう）。そのあとはふつうに Space で変換します。ヘボン式（shi・tsu・ji）でも訓令式（si・tu・zi）でもかまいません
- 日本語がオフのときは、英単語を入れます。前に語があれば、間に空白を入れます。Shift を押してからなぞると、頭を大文字にします
- ほかの候補は候補の窓に出ます。押すと、入れた語と置き換わります
- 同じ文字が続く綴り（「っ」の kk など）や伸ばす音の違い（たのし・たのしい）は、なぞる形が同じになります。よく使う方が先に出るので、違うときは候補から選んでください
- 語は1つずつなぞります（日本語は Mozc の辞書の読みから約6万、英語は約5万語）
- 左下の ?123 で数字・記号のページ、そこの =\< でその他の記号（「」・€ など）のページに替わります。ABC で文字に戻ります
- ?123 は上に払うと配列の切り替え、下に払うとフロートです。あ/A・Space・Backspace の払いはフルキーと同じです

### フルキー（QWERTY）

Unexpected Keyboard と同じ考え方で、ショートカットもそのまま使えます。

- キーを隅や上下左右へ払うと、小さく書いてある文字が出ます（上の段の右上が数字、左上が記号。2段目も右上・左上に記号）
- Shift・Ctrl・Alt・Fn は、押すと次の1打だけ効きます。2回続けて押すと固定します（もう一度押すと外れます）。効いているあいだはキーがピル型になります
- 修飾キーを押したまま別のキーを押す同時押しもできます（Ctrl を押したまま a で全選択、Shift を押したまま Space を左へ払うと1文字ずつ選択）。修飾キーの押す・離すもアプリへ送るので、Shift＋矢印の選択やアプリのショートカットが物理キーボードと同じように使えます
- Ctrl を上に払うとフリックに切り替わり、下に払うとキーボードを浮かせます（フリックの「あa1」と同じ位置・向きです）
- Alt を上に払うと Meta（⌘。Windows キーにあたります）です
- Fn＋数字で F1〜F10、Fn＋`-` `=` で F11・F12 です（`-` は g、`=` は h の右上）
- Space を横にドラッグすると、指の動きに合わせてカーソルが動きます（Shift などが効いていれば選択します）。短く払うと1文字動きます
- Tab のキーは、上下左右に払うと矢印、四隅に払うと Home・End・PgUp・PgDn です
- Backspace は長押しで続けて消します。右に払うと Delete です。文字のキーも、長押しすると繰り返します
- あ/A のキーで日本語のオン/オフを切り替えます。上に払うと絵文字パネル、下に払うとクリップボードが開きます
- マイクのキーは、押している間だけ録音します（録音キーと同じです）。短く押すと聞き続けます

### フリック

Gboard と同じ考え方の12キーです。真ん中の文字のキーを押すと「あ」、左・上・右・下に払うと「い・う・え・お」が入ります。

- 「小゛゜」で、直前の文字に濁点・半濁点・小書きを付け外しします（か→が、は→ば→ぱ、つ→っ→づ）
- 同じキーを続けて押すと、次の文字になります（トグル入力。設定で切れます）。↶ で1つ戻します
- 「あa1」で、かな・英字・数字を切り替えます。上に払うと QWERTY になります
- ☺ を押すと絵文字、左に払うとクリップボード、上に払うと音声入力です
- 右の列は Backspace・→・空白（入力中は変換）・Enter です
- 広い画面（Fold の内側の画面など）では、Gboard と同じく左右に分かれます

### 絵文字

上のタブで種類を選びます。時計のタブは、最近使ったものです。左下の「ABC」（日本語入力中は「あ」）でキーボードに戻ります。

「絵文字を検索」を押すと、下にキーボードが出て、ローマ字・かな・英語で探せます（neko・ねこ・猫・cat など）。ふつうに変換もでき、候補は結果の行に並びます。広い画面では、検索の欄が種類のタブの横に並びます。

### クリップボード

コピーした文字や画像の履歴です。押すと貼り付け、長押しでピン留め・切り抜き（画像のとき）・削除ができます。

- ピン留めしていないものは、新しい30件まで残します
- パスワードなど、機密の印が付いたコピーは残しません。設定の「コピーの履歴を残す」で切れます
- 画像を直接受け付けない入力欄では、画像をクリップボードに入れて知らせます。入力欄を長押しして貼り付けてください

## 音声入力

録音キー（既定 F12、画面キーボードではマイクのキー）を押している間だけ録音し、離すと端末の中のモデルで文字にして入れます。音声は外へ送りません。

1. マイクを許可します
2. 設定の「音声入力」の一覧から、モデルを「ダウンロード」します（Wi-Fi でなければ、ダウンロードしてよいか確かめます。ダウンロードしている間は、設定画面を開いたままにしてください。もう一度押すとやめ、次は続きからダウンロードします）
3. 使うモデルの「適用」を押します（使っているモデルに「使用中」が付きます）
4. 「見本の音声で測る」で、ダウンロードしたモデルすべての速さと結果を比べられます
5. 録音キーは「録音キー」のボタンで変えられます（一覧から選ぶか、物理キーボードのキーを押します）

録音中はカーソルの近くに「🎤」、認識中は「…」が出ます。無音や雑音だけのときは、何も入れません。

### モデル

話している途中の文字は ReazonSpeech で出し、入力欄に入る文字は「適用」したモデルで作ります。各モデルには、言語・精度・速さ・句読点・大きさの札が付きます。

| モデル | 大きさ | 札 |
|---|---|---|
| parakeet-ja | 656MB | 日本語・精度 高・速い・句読点あり（NVIDIA の日本語専用） |
| ReazonSpeech | 73MB | 日本語・精度 高・とても速い・句読点なし（途中の表示にも使います。句読点は話して入れます） |
| SenseVoice | 239MB | 中・英・日・韓・精度 中・速い・句読点あり |
| whisper small | 190MB | 多言語・精度 低・遅い・句読点あり |
| kotoba-whisper v2.0 | 538MB | 日本語・精度 高・とても遅い・句読点 少 |
| whisper large-v3-turbo | 574MB | 多言語・精度 高・とても遅い・句読点あり |

適用したモデルがダウンロードされていなければ、ダウンロードしてあるほかのモデルを使います（一覧の上にそう出ます）。要らなくなったモデルは「削除」で消せます。話している途中の文字を出すには、ReazonSpeech をダウンロードし、「話しながら文字を出す」をオンにします（既定でオンです）。

「リストにないモデルを取り込む」で、一覧にないモデルのファイルを選んで足せます。形式はファイル名から見当をつけ、取り込む前に確かめます。

- whisper.cpp（ggml）: ggml-〜.bin のファイル1つ
- sherpa-onnx のトランスデューサ（zipformer など）: encoder・decoder・joiner の .onnx と tokens.txt
- sherpa-onnx の NeMo CTC（parakeet など）: model の .onnx と tokens.txt
- sherpa-onnx の SenseVoice: model の .onnx と tokens.txt

### 聞き続けるモード

録音キー（マイクのキー）を短く押すと、iPhone や Pixel の音声入力のように聞き続けます。話し終わる（0.7 秒ほど黙る）たびに、そこまでを文字にしてカーソルの位置に入れます。

- 聞いている間も、キーボードで打てます。入力中の文字があるときに認識が終わったら、その文字が確定してから入れます
- 話している途中の文字は、入力欄に未確定の文字として出ます（Termux などでは帯に出ます）。キーを押すといったん消え、話している間はまた出ます
- もう一度押すと終わります（話している途中なら、そこまでを入れます）。1分話さないときや、別の入力欄に移ったときも終わります
- 画面キーボードのマイクのキーは、聞いている間は色が変わります

### 話して入れる句読点

「くてん」「とうてん」のように言うと、記号になります（設定の「話して句読点を入れる」で切れます）。

| 言う | 入る |
|---|---|
| くてん | 。 |
| とうてん | 、 |
| かいぎょう | 改行 |
| かいだんらく | 改行2つ |
| はてなマーク・ぎもんふ | ？ |
| びっくりマーク・かんたんふ | ！ |
| かぎかっこ／かぎかっことじ | 「／」 |
| かっこ／かっことじ | （／） |
| なかぐろ | ・ |

モデルが自分で付けた句読点と重なったら、一つにまとめます。「かっこいい」などのふつうの言葉は、そのままにします。

## 設定の書き出しと読み込み

設定の「書き出しと読み込み」で、設定・ユーザー辞書・スニペットを1つのファイル（JSON）に書き出せます。別の端末に移すときや、控えを取っておくときに使います。

- 学習した変換・クリップボードの履歴・キー記録・音声モデルは入りません
- 読み込むと、今の設定・ユーザー辞書・スニペットはファイルの中身に置き換わります。元に戻したいときは、先に今の設定を書き出しておいてください
- 音声入力で取り込んだモデルを「適用」していた場合、移した先の端末にそのモデルがなければ、ある中から使えるモデルを使います

## 入力中の文字を出せないアプリ

Termux のように入力中の文字をうまく出せないアプリでは、入力中の文字を候補の窓に出し、確定したものだけをアプリへ送ります。設定の「入力中の文字を帯に出すアプリ」に、パッケージ名を足せます（既定は `com.termux`）。
