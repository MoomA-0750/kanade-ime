# Kanade の使い方

物理キーボード専用の日本語 IME。画面キーボードは出さない。

## はじめに

1. 「Kanade の設定」→「入力方法の設定を開く」で Kanade を有効にし、「入力方法を選ぶ」で選ぶ
2. 「候補の帯」の「重ねて表示を許可する」で、他のアプリの上に重ねて表示を許可する（候補・入力中の文字・「あ」「A」をカーソルの近くに出すため。許可しないと Galaxy では候補が出ないことがある）

## 画面キーボード

物理キーボードがつながっていないときだけ、画面の下にキーボードが出る（設定画面の「画面キーボード」で「いつも出す」「出さない」にもできる）。Unexpected Keyboard と同じ考え方で、ショートカットもそのまま使える。

- キーを隅や上下左右へ払うと、小さく書いてある文字が出る（上の段の右上が数字、左上が記号。2段目も右上・左上に記号）
- ⇧・Ctrl・Alt・Fn は、押すと次の1打だけ効く。2回続けて押すと固定（もう一度押すと外れる）
- 物理キーボードと同じく、修飾キーを押したまま別のキーを押す同時押しもできる（Ctrl を押したまま a で全選択、⇧ を押したまま Space を左へ払うと1文字ずつ選択）。修飾キーの押す・離すもアプリへ送るので、Shift＋矢印の選択やアプリのショートカットが物理キーボードと同じに効く
- Alt を上に払うと Meta（◆。Windows キー・⌘ にあたる）
- 🎤 は押している間だけ録音（録音キーと同じ）。下に今の録音キーが出る
- 高さと下の余白は設定画面の「画面キーボード」で変えられる（ナビゲーションバーに重なる端末では下の余白を増やす）
- Fn＋数字で F1〜F10、Fn＋`-` `=` で F11・F12（`-` は g、`=` は h の右上）
- ⇥ のキーは、上下左右に払うと矢印、四隅に払うと Home・End・PgUp・PgDn
- ⌫ は長押しで続けて消す。右に払うと Delete
- 配列は QWERTY とフリックがある（設定の「画面キーボード」→「配列」、または QWERTY では Esc を上に払う、フリックでは「あa1」を上に払う）
- あ/A のキーを下に払うとクリップボード（コピーした文字・画像の履歴。押すと貼り付け、長押しでピン留め・切り抜き・削除。パスワードなど機密の印が付いたコピーは残さない。設定で履歴を切れる）
- あ/A のキーで日本語オン/オフ。上に払うと絵文字パネル（上のタブで種類を選ぶ。時計のタブは最近使ったもの。左下の ABC／あ でキーボードに戻る）
- 絵文字パネルの「絵文字を検索」を押すと、その下にキーボードが出て、ローマ字・かな・英語で探せる（neko・ねこ・cat など。日本語の読みと名前は Mozc の絵文字のデータから）。広い画面では検索の欄が種類のタブの横に並ぶ
- Space を横にドラッグすると、指の動きに合わせてカーソルが動く（Shift などが効いていれば選択）。短く払うと1文字
- 文字のキーを長押しすると繰り返す
- 押したキーは物理キーボードと同じように扱う。日本語入力・変換・F6〜F10（Fn＋6〜0）・Ctrl+U/I/O/P/T がそのまま使え、IME で使わないキー（Ctrl+C、Ctrl+Z、端末アプリの Ctrl+D など）はアプリへそのまま送る

## 日本語のオン/オフ

| キー | 動き |
|---|---|
| 変換・かな（JIS） | オン |
| 無変換・英数（JIS） | オフ |
| 半角/全角（JIS） | 切り替え |
| 右 Alt の単押し・Ctrl+Space・F13（US、設定で選ぶ） | 切り替え |

切り替えると、カーソルの近くに「あ」「A」が少し出る。

句読点（`,` と `.` で入るもの）は設定画面で「、。」「，．」「、．」「，。」から選べる。

## 入力中（Space を押す前）

| キー | 動き |
|---|---|
| 文字 | ローマ字でかなに。打つたびに変換結果が出る（ライブ変換。設定で切れる） |
| Enter | 見えているものを確定 |
| Space・↓ | 変換を始める（文節に分かれ、候補の窓が出る） |
| ←→・Home・End | 未確定文字列の中でカーソルを動かす。途中にあるあいだはかなで見え、末尾に戻ると変換結果に戻る |
| Backspace・Delete | カーソルの前・後ろの1文字を消す |
| Shift+←→ | 変換を始めて、最初の文節を縮める・伸ばす |
| F6〜F10・Ctrl+U/I/O/P/T | ひらがな・カタカナ・半角カナ・全角英数・半角英数 |
| Esc | 全部取り消し |

## 変換中（Space を押したあと）

| キー | 動き |
|---|---|
| Space・↓、Shift+Space・↑ | 選んでいる文節の次・前の候補 |
| 1〜9 | その番号の候補を選んで次の文節へ（文節が1つなら確定） |
| 候補を指で触る | 1〜9 と同じ。候補の窓は指でスクロールできる |
| ←→ | 文節を移る |
| Shift+←→ | 選んでいる文節を1文字縮める・伸ばす |
| Enter | 全体を確定 |
| 文字 | いまの変換を確定して、次の入力を始める |
| Esc・Backspace | 変換をやめてかなに戻る |

候補の右には「ユーザー辞書」「ひらがな」「カタカナ」「記号」「絵文字」「全角」「半角」などの説明が出る。
その読みの辞書の語はすべて候補に出る。記号（「やじるし」→「→」）や絵文字（「えがお」→「😀」）も出る。
「きょう」「あした」「きのう」などでは日付（2026/10/03、10月3日（土）、令和8年10月3日 など）、「いま」では時刻、「ことし」「らいねん」では年も候補に出る。

## 学習

変換で、最初に出た候補と違うものを選んで確定すると、その読みの候補として覚える。次からは候補の上の方に出て、入力中の変換（ライブ変換）でも使われやすくなる。設定画面の「学習する」で切れ、「学習を消す」で覚えたものを消せる（ユーザー辞書は消えない）。

## ユーザー辞書

読み（ひらがな）と語を登録する。登録した語は変換で優先され、候補の先頭に出る（macOS のユーザ辞書と同じ）。文の途中でも、その読みの部分に使われやすくなる。

- 設定画面の「ユーザー辞書」で、一覧（「追加」、行を触って編集・削除）か、テキスト（まとめて登録・コピーで書き出し）で編集する
- テキストの書式: 1行に `よみ 語`（最初の空白で区切る）。`#` で始まる行は無視される

```
かなで Kanade
でっくす DeX
```

## スニペット

キーを打ち終わった瞬間に、出力へ置き換わる。日本語入力中も直接入力中も効く。

- キーは打つ文字そのもの（日本語入力中でも、かなや全角になる前の文字で見る）
- 英字だけのキー（`sig` など）は、日本語入力中のローマ字にも反応する。記号を含むキー（`@@`、`->`）がおすすめ
- 長いキーが優先される（`->` と `-->` があれば `-->`）
- 日本語入力中は、キーより前の未確定文字列をいま見えている形で確定してから置き換える。直接入力中は、カーソルの前を確かめてから置き換える（カーソルを動かしていたら置き換えない）
- テキストの書式: 1行に `キー 出力`（最初の空白で区切る）。出力の中の `\n` は改行。`#` で始まる行は無視される

```
@@ you@example.com
-> →
<- ←
=> ⇒
sig お世話になっております。\nよろしくお願いいたします。
```

## 音声入力

録音キー（既定 F12）を押している間だけ録音し、離すと端末内のモデルで文字にして入れる。音声は外へ送らない。

1. マイクを許可する（許可していなければ、設定画面の左の一番上に案内が出る）
2. 設定画面の「音声入力」の一覧から、モデルを「ダウンロード」する（Wi-Fi でなければ、ダウンロードしてよいか訊く。落としている間は設定画面を開いたままにする。もう一度押すとやめ、次は続きから落とす）
3. 使うモデルの「適用」を押す（使っているモデルに「使用中」が付く）
4. 「見本の音声で測る」で、落としてあるモデルすべての速さと結果を比べられる
5. 録音キーは「録音キー」のボタンで変えられる（一覧から選ぶか、物理キーボードのキーを押す）。画面キーボードではマイクのキー

録音中はカーソルの近くに「🎤」、認識中は「…」が出る。無音や雑音だけのときは何も入れない。

### モデル

話している途中の文字はいつも ReazonSpeech で出し、入力欄に入る文字（確定の文）は「適用」したモデルで作る。各モデルには、言語・精度・速さ・句読点・大きさの札が付く。

| モデル | 大きさ | 札 |
|---|---|---|
| parakeet-ja | 656MB | 日本語・精度 高・速い・句読点あり（NVIDIA の日本語専用） |
| ReazonSpeech | 73MB | 日本語・精度 高・とても速い・句読点なし（途中の表示にも使う。句読点は話して入れる） |
| SenseVoice | 239MB | 中・英・日・韓・精度 中・速い・句読点あり |
| whisper small | 190MB | 多言語・精度 低・遅い・句読点あり |
| kotoba-whisper v2.0 | 538MB | 日本語・精度 高・とても遅い・句読点 少 |
| whisper large-v3-turbo | 574MB | 多言語・精度 高・とても遅い・句読点あり |

適用したモデルを落としていなければ、落としてあるほかのモデルを使う（一覧の上にそう出る）。要らなくなったモデルは「削除」で消せる。調べた結果は `docs/RESEARCH-voice.md`。

「リストにないモデルを取り込む」で、一覧にないモデルのファイルを選んで足せる。形式はファイル名から見当をつけ、取り込む前に確かめる。

- whisper.cpp（ggml）: ggml-〜.bin のファイル1つ
- sherpa-onnx のトランスデューサ（zipformer など）: encoder・decoder・joiner の .onnx と tokens.txt
- sherpa-onnx の NeMo CTC（parakeet など）: model の .onnx と tokens.txt
- sherpa-onnx の SenseVoice: model の .onnx と tokens.txt

### フリック配列

Gboard と同じ考え方の12キー。真ん中の文字のキーを押すと「あ」、左・上・右・下に払うと「い・う・え・お」。

- 「小゛゜」で直前の文字に濁点・半濁点・小書きを付け外し（か→が、は→ば→ぱ、つ→っ→づ）
- 同じキーを続けて押すと次の文字になる（トグル入力。設定で切れる）。↶ で1つ戻す
- 「あa1」でかな・英字・数字を切り替える。上に払うと QWERTY へ
- ☺ を押すと絵文字、左に払うとクリップボード、上に払うと音声入力
- 右の列は ⌫・▶・空白（入力中は変換）・⏎
- 広い画面（600dp 以上）では、Gboard と同じく左右に分かれる

### 聞き続けるモード

録音キー（🎤）を短く押すと、iPhone や Pixel の音声入力のように聞き続ける。話し終わる（0.7 秒ほど黙る）たびに、そこまでを文字にしてカーソルの位置に入れる。

- 聞いている間もキーボードで打てる。入力中の文字があるときに認識が終わったら、その文字が確定してから入れる
- 話している途中の文字は、入力欄に未確定の文字として出る（Termux などでは帯に）。キーを押すといったん消え、話している間はまた出る
- もう一度押すと終わる（話している途中なら、そこまでを入れる）。1分話さなければ終わる。別の入力欄に移っても終わる
- 画面キーボードのマイクのキーは、聞いている間は色が変わる

### 話して入れる句読点

「くてん」「とうてん」のように言うと記号になる（設定の「話して句読点を入れる」で切れる）。

| 言う | 入る |
|---|---|
| くてん | 。 |
| とうてん | 、 |
| かいぎょう | 改行 |
| かいだんらく | 改行2つ |
| はてなマーク・ぎもんふ | ？ |
| びっくりマーク・かんたんふ | ！ |
| かぎかっこ／かぎかっことじ | 「／」 |
| かっこ／かっことじ | （／） |
| なかぐろ | ・ |

whisper が自分で付けた句読点と重なったら一つにまとめる。「かっこいい」などの普通の言葉はそのまま。

### 話しながら文字を出す

ReazonSpeech（約 73MB）を入れると、話している途中から文字が未確定文字列として出る。離すと whisper（取り込んであれば）で句読点の付いた文にして確定する（whisper がなければ ReazonSpeech の結果で確定する）。

1. 「ReazonSpeech をダウンロード」を押す（4つのファイルをまとめて落とす。手元にあれば「ファイルから取り込む（4つ）」で選ぶ）
2. 「話しながら文字を出す」を入れる（既定で入っている）

## 未確定文字列を出せないアプリ

Termux のように未確定文字列をうまく出せないアプリでは、入力中の文字を候補の窓に出し、確定したものだけをアプリへ送る。設定画面の「入力中の文字を帯に出すアプリ」にパッケージ名を足せる（既定は `com.termux`）。
