# Kanade の使い方

物理キーボードのための日本語入力です。物理キーボードがつながっていないときは、画面キーボードで入力できます。

## はじめに

1. Kanade の設定を開くと、足りない設定があるときだけ、左の一番上に案内が出ます。案内に沿って、Kanade を入力方法として有効にし、Kanade に切り替えます
2. 「他のアプリの上に重ねて表示」を許可します。変換候補と「あ」「A」の表示を、カーソルの近くに出すのに使います（許可しないと、Galaxy で物理キーボードを使っているときに候補が出ないことがあります）
3. 音声入力を使うときは、マイクも許可します

## 日本語のオン/オフ

| キー | 動き |
|---|---|
| 変換・かな（JIS） | オン |
| 無変換・英数（JIS） | オフ |
| 半角/全角（JIS） | 切り替え |
| 右 Alt の単押し・Ctrl+Space・F13（US、設定で選びます） | 切り替え |

切り替えると、カーソルの近くに「あ」「A」が少しのあいだ出ます。

句読点（`,` と `.` で入るもの）は、設定の「入力と変換」で「、。」「，．」「、．」「，。」から選べます。

## 入力中（Space を押す前）

| キー | 動き |
|---|---|
| 文字 | ローマ字をかなにします。打つたびに変換した結果を出します（ライブ変換。設定で切れます） |
| Enter | 見えているものを確定します |
| Space・↓ | 変換を始めます（文節に分かれ、候補の窓が出ます） |
| ←→・Home・End | 入力中の文字の中でカーソルを動かします。途中にいるあいだはかなで見え、末尾に戻ると変換した結果に戻ります |
| Backspace・Delete | カーソルの前・後ろの1文字を消します |
| Shift+←→ | 変換を始めて、最初の文節を縮めます・伸ばします |
| F6〜F10・Ctrl+U/I/O/P/T | ひらがな・カタカナ・半角カナ・全角英数・半角英数にします |
| Esc | 全部取り消します |
| Tab | 予測の候補を出しているとき、その中で次の候補を選びます（Enter で入れます） |

### 予測の候補

設定の「入力と変換」→「予測の候補」をオンにすると、打っている途中で続きを予測した語を候補の窓に出します（「きーぼ」→ キーボード、「ありがと」→ ありがとう・ありがとうございます）。前に変換した文節はそのままで、最後の語の続きを出します（「きょうはきーぼ」→ 今日はキーボード）。候補を指で触るか、Tab で選んで Enter で入れます。はじめはオフです。候補は zenz が前の文とのつながりで並べ直すので、少し遅れて順番が変わることがあります。

### zenz の使い方とプロフィール

変換は、辞書の候補を zenz（小さな言語モデル）が直して決めます。設定の「入力と変換」→「zenz の使い方」で選べます。

- **確かめて直す**（はじめはこちら）: 辞書の1位を zenz が確かめ、違うと見た所から辞書を探し直します（azooKey の Zenzai と同じ方式）。計算が少なく速いです
- **並べ替え**: 辞書の上位10件を zenz が採点して並べ替えます

どちらも当たる数は同じくらいで、間違え方が少し違います。自分で選び直して覚えさせた語が入った変換は、zenz が動かしません。

「変換のプロフィール」に自分のこと（「プログラマ。技術の話が多い」など、25文字まで）を書くと、zenz がそれに合う語を選びやすくなります。

### テンキーの打ち間違い

画面のテンキーで打っているときは、濁点や小さい字の付け忘れを直した候補も出します（「しやしん」→ 写真、「ちよつと」→ ちょっと）。打ったとおりの変換も、候補の上から3つ以内に必ず残します。

## 再変換

Kanade で確定した文字をアプリで選んで Space（物理キーボードでは変換キーも）を押すと、選んだ文字を変換し直します。確定したときの文節の区切りと表記のままで変換中になるので、直したい文節だけ候補を選び直せます。Esc で元の文字に戻ります。

- 読みは、Kanade が確定したときに覚えたもの（新しい 300 件）から引きます。ひらがな・カタカナ・記号はそのまま読みにします。ほかのキーボードで入れた漢字や、IME を入れ直す前の文字は読みが分からないので、Space はふだんどおり（選んだ文字を空白に置き換え）になります
- 学習しないよう求める入力欄（シークレットモードなど）で確定したものは覚えません

## カタカナの英語の表記

カタカナの読みで打った語は、変換の候補に英語の表記も出ます（アップル→Apple、グーグル→Google、ニューヨーク→New York、キーボード→keyboard）。候補の窓では「英語」と書いてあります。表に無い語も、長音の有る無し（コンピュータ／コンピューター）を試し、表にある語をつないで出します（ワールドカップ→World Cup）。

## 括弧

日本語入力で「（ などの開き括弧を打つと、閉じ括弧も入れてカーソルを中に置きます（設定の「入力と変換」で切れます）。中に打った文字はふつうにライブ変換されます。

- 閉じ括弧を打つと、入れずに後ろへ進みます
- 空の括弧のまま Backspace を押すと、両方消えます
- 空の括弧で Space を押すと、（）→「」→『』→【】→［］→｛｝…と替わります（Shift+Space で逆順。候補の窓からも選べます）。テンキーの「や」で打った（ から、ほかの括弧にするときに使います
- 変換のときに括弧1文字の文節があれば、ほかの括弧も候補に出ます

## 変換中（Space を押したあと）

| キー | 動き |
|---|---|
| Space・↓、Shift+Space・↑ | 選んでいる文節の、次・前の候補にします |
| 1〜9 | その番号の候補を選んで、次の文節へ進みます（文節が1つなら確定します） |
| 候補を指で触る | 1〜9 と同じです。候補の窓は指でスクロールできます |
| ←→ | 文節を移ります |
| Shift+←→ | 選んでいる文節を1文字縮めます・伸ばします |
| Enter | 全体を確定します |
| 文字 | いまの変換を確定して、次の入力を始めます |
| Esc・Backspace | 変換をやめて、かなに戻ります |

候補の右には「ユーザー辞書」「ひらがな」「カタカナ」「記号」「絵文字」「全角」「半角」などの説明が出ます。
その読みの辞書の語は、すべて候補に出ます。文節が「語＋助詞など」のとき（「かんじが」）は、語の読みの辞書の語すべてに後ろを付けたもの（漢字が・感じが・幹事が・監事が…）も出ます。記号（「やじるし」→「→」）や絵文字（「えがお」→「😀」）も出ます。
「きょう」「あした」「きのう」などでは日付（2026/10/03、10月3日（土）、令和8年10月3日 など）、「いま」では時刻、「ことし」「らいねん」では年も候補に出ます。

## 学習

変換で、最初に出た候補と違うものを選んで確定すると、その読みの候補として覚えます。次からは候補の上の方に出て、ライブ変換でも使われやすくなります。設定の「学習する」で切れ、「学習を消す」で覚えたものを消せます（ユーザー辞書は消えません）。

## ユーザー辞書

読み（ひらがな）と語を登録します。登録した語は変換で優先され、候補の先頭に出ます（macOS のユーザ辞書と同じです）。文の途中でも、その読みの部分に使われやすくなります。

- 設定の「ユーザー辞書」で、一覧（「追加」、行を触って編集・削除）か、テキスト（まとめて登録・コピーで書き出し）で編集します
- テキストの書式は、1行に `よみ 語` です（最初の空白で区切ります）。`#` で始まる行は無視します

```
かなで Kanade
でっくす DeX
```

## スニペット

キーを打ち終わった瞬間に、出力へ置き換えます。日本語入力中も直接入力中も使えます。

- キーは打つ文字そのものです（日本語入力中でも、かなや全角になる前の文字で見ます）
- 英字だけのキー（`sig` など）は、日本語入力中のローマ字にも反応します。記号を含むキー（`@@`、`->`）がおすすめです
- 長いキーが優先されます（`->` と `-->` があれば `-->`）
- 日本語入力中は、キーより前の入力中の文字をいま見えている形で確定してから置き換えます。直接入力中は、カーソルの前を確かめてから置き換えます（カーソルを動かしていたら置き換えません）
- テキストの書式は、1行に `キー 出力` です（最初の空白で区切ります）。出力の中の `\n` は改行です。`#` で始まる行は無視します

```
@@ you@example.com
-> →
<- ←
=> ⇒
sig お世話になっております。\nよろしくお願いいたします。
```

## 画面キーボード

物理キーボードがつながっていないときだけ、画面の下にキーボードが出ます（設定の「画面キーボード」で「いつも」「出さない」にもできます）。配列は「グライド」「フルキー」「テンキー」の3つです。設定の「配列」で使うものを選びます（はじめはグライドとテンキー）。キーボードの左下のキーを上に払うと、使う配列の中で次の配列に替わります。

押したキーは物理キーボードと同じように扱います。日本語入力・変換・F6〜F10・Ctrl+U/I/O/P/T がそのまま使え、IME で使わないキー（Ctrl+C、Ctrl+Z、端末アプリの Ctrl+D など）はアプリへそのまま送ります。高さ（300% まで）と下の余白は、設定の「画面キーボード」で変えられます（ナビゲーションバーに重なる端末では、下の余白を増やしてください）。

### 配列ごとの言語と、配列の一覧

設定の「配列」で、配列ごとに使う言語（日本語・英語・数字/記号）を選べます（例: テンキーは日本語だけ、グライドは英語と数字/記号）。

- あ/A（テンキーは「あa1」）を押すと、その配列で使う言語の中で次へ替わります。その配列で使う言語が1つだけなら、次の配列へ移ります（上の例なら、テンキーの「あa1」でグライドの英語、グライドの あ/A でテンキーの日本語）
- あ/A・「あa1」を長押しすると、配列ごとにまとめた一覧（「テンキー」の下に 日本語・英語・数字/記号 など）が出て、選んだものに替わります（iPhone の地球儀のキーの長押しと同じです）
- 左下のキーを上に払って配列を替えたときも、言語はその配列で使うものに合わせます
- グライドで数字/記号を使わない設定なら、?123 で数字/記号を使えるテンキーへ移ります
- 物理キーボードで日本語のオン/オフを替えたときも、いまの配列でその言語を使わない設定なら、使える配列へ移ります

### 折りたたみの端末

- 本のように開いて折り曲げたとき（折り目が縦で半開き）は、フルキー・グライド・テンキーのどれも折り目の左右に分かれ、折り目の上にはキーを置きません（qwert｜yuiop、asdfg｜ghjkl、zxcv｜vbnm。g・v・Space は両側にあります）。平らに開くと1つに戻ります
- 設定の「画面キーボード」→「大きさ」の「折り目で左右に分ける」で、「平らでも」（平らに開いていても分ける）・「折ったときだけ」（既定）・「分けない」を選べます
- 半開き（L 字）で折り目が横になったとき（横向きの Fold、縦向きの Flip）は、キーボードが画面の下から折り目までを埋めます。上半分はアプリに残ります。平らに開くと、設定の高さに戻ります
- 折り曲げる・広げるとき、キーは滑らかに分かれたり伸びたりします
- フロートで浮かせているときは、どちらもしません

### フロート

キーボードを画面の下から離して、好きな位置・幅に浮かせられます（キーボードの左下のキー（?123・Ctrl・「あa1」）を下に払う）。浮かせている間はアプリの画面が縮まず、キーボードの外を触ると下のアプリを操作できます。

- キーボードの下のつまみの真ん中をドラッグすると動かせます
- つまみを勢いよく払うと、そのまま滑っていきます。画面の端に当たると少し外へはみ出して跳ね返り、端に収まります
- つまみの右端（↔）をドラッグすると幅が変わります
- つまみの左端を押すと、画面の下に戻ります
- 位置と幅は覚えておき、次に出したときも同じ所に出します

### グライド

QWERTY の文字のキーの上を、指を離さずになぞると語を入れます（Gboard のグライド入力と同じです）。文字のキーには払いの記号を置いていないので、指を動かすとすぐにグライドになります。動かさずに離せば、ふつうにその文字を打ちます。

- 日本語がオンのときは、ローマ字の綴りでなぞると、かなを入力中の文字として入れます（「arigatou」→ ありがとう）。そのあとはふつうに Space で変換します。ヘボン式（shi・tsu・ji）でも訓令式（si・tu・zi）でもかまいません
- 日本語がオフのときは、英単語を入れます。前に語があれば、間に空白を入れます。Shift を押してからなぞると、頭を大文字にします
- ほかの候補は候補の窓に出ます。押すと、入れた語と置き換わります
- なぞった直後に Backspace を押すと、入れた語を丸ごと消します（英語は前に足した空白も）。そのまま、なぞり直せます
- 日本語は、入力中の読みのあとに自然につながる語を先に出します（「ほんが」のあとの aru は「ある」、など）
- さらに zenz（変換の並べ替えに使う言語モデル）に、前の文とのつながりを見てもらいます。辞書の1位を先に入れ、zenz が別の語を選んだら少し遅れて入れ替わります（「かおを」のあとの arau が「表す」から「洗う」に、など）。設定の「配列」で切れます
- グライドで入れて残した語は覚えて、次から先に出します（直後に消した語・選び直した語は数えません）
- 同じ文字が続く綴り（「っ」の kk など）や伸ばす音の違い（たのし・たのしい）は、なぞる形が同じになります。よく使う方が先に出るので、違うときは候補から選んでください
- 語は1つずつなぞります（日本語は Mozc の辞書の読みから約6万、英語は約3万2千語。英語は i'm・don't のような短縮形も入っています）
- 左下の ?123 で数字・記号のページ、そこの =\< でその他の記号（「」・€ など）のページに替わります。ABC で文字に戻ります
- ?123 は上に払うと配列の切り替え、下に払うとフロートです。あ/A・Space・Backspace の払いはフルキーと同じです

### タップのずれの補い

グライドとテンキーでは、キーの境目あたりを触ったとき、入力中の語のあとに来やすい文字のキーにします（iPhone のキーボードと同じ考え方です。「th」のあとで e と w の境目を触れば e）。テンキーは、斜めに払って向きがはっきりしないときも同じように選びます。キーの真ん中あたりを触ったときは、そのキーのままです。設定の「画面キーボード」→「操作」で切れます。

### フルキー（QWERTY）

Unexpected Keyboard と同じ考え方で、ショートカットもそのまま使えます。

- キーを隅や上下左右へ払うと、小さく書いてある文字が出ます（上の段の右上が数字、左上が記号。2段目も右上・左上に記号）
- Shift・Ctrl・Alt・Fn は、押すと次の1打だけ効きます。2回続けて押すと固定します（もう一度押すと外れます）。効いているあいだはキーがピル型になります。配列を替える（グライド・テンキーへ移る）と外れます
- 修飾キーを押したまま別のキーを押す同時押しもできます（Ctrl を押したまま a で全選択、Shift を押したまま Space を左へ払うと1文字ずつ選択）。修飾キーの押す・離すもアプリへ送るので、Shift＋矢印の選択やアプリのショートカットが物理キーボードと同じように使えます
- Ctrl を上に払うとテンキーに切り替わり、下に払うとキーボードを浮かせます（テンキーの「あa1」と同じ位置・向きです）
- Alt を上に払うと Meta（⌘。Windows キーにあたります）です
- Fn＋数字で F1〜F10、Fn＋`-` `=` で F11・F12 です（`-` は g、`=` は h の右上）
- Space を横にドラッグすると、指の動きに合わせてカーソルが動きます（Shift などが効いていれば選択します）。短く払うと1文字動きます
- Tab のキーは、上下左右に払うと矢印、四隅に払うと Home・End・PgUp・PgDn です
- Backspace は長押しで続けて消します。右に払うと Delete です。文字のキーも、長押しすると繰り返します。繰り返し始めるまでの待ちと繰り返す速さは、設定の「画面キーボード」→「操作」で変えられます
- あ/A のキーで日本語のオン/オフを切り替えます。上に払うと絵文字パネル、下に払うとクリップボードが開きます
- マイクのキーは、押している間だけ録音します（録音キーと同じです）。短く押すと聞き続けます

### テンキー

Gboard と同じ考え方の12キーです。真ん中の文字のキーを押すと「あ」、左・上・右・下に払うと「い・う・え・お」が入ります。

- 「小゛゜」で、直前の文字に濁点・半濁点・小書きを付け外しします（か→が、は→ば→ぱ、つ→っ→づ）
- 同じキーを続けて押すと、次の文字になります（トグル入力。設定で切れます）。↶ で1つ戻します
- ↶ を払うと、左で全選択・右でやり直し・上でコピー・下で貼り付けです（Ctrl+A・Ctrl+Shift+Z・Ctrl+C・Ctrl+V を送ります）
- 「あa1」で、かな・英字・数字を切り替えます。上に払うと QWERTY になります
- ☺ を押すと絵文字、払うとクリップボードです
- マイクのキーは、押している間だけ録音します（QWERTY のマイクと同じです）。短く押すと聞き続けます
- 左の列は ↶・☺・マイク・「あa1」、右の列は Backspace・Tab・空白（入力中は変換）・Enter です
- Tab のキーは QWERTY の Tab と同じで、上下左右に払うと矢印、四隅に払うと Home・End・PgUp・PgDn です。矢印と PgUp・PgDn は払ったまま押し続けると繰り返します
- 変換中は Tab のキーが「文節」のキーになります。左に払うと選んでいる文節を縮め、右に払うと伸ばします（物理キーボードの Shift+←→）。押す・右上に払うと次の文節、左上に払うと前の文節、上下に払うと前・次の候補です。文節を縮めてから候補を選ぶと、次の文節へ進みます
- 広い画面（Fold の内側の画面など）では、Gboard と同じく左右に分かれます

### 絵文字

上のタブで種類を選びます。時計のタブは、最近使ったものです。左下の「ABC」（日本語入力中は「あ」）でキーボードに戻ります。

「絵文字を検索」を押すと、下にキーボードが出て、ローマ字・かな・英語で探せます（neko・ねこ・猫・cat など）。ふつうに変換もでき、候補は結果の行に並びます。広い画面では、検索の欄が種類のタブの横に並びます。

### クリップボード

コピーした文字や画像の履歴です。押すと貼り付け、長押しでピン留め・編集（文字のとき）・切り抜き（画像のとき）・削除ができます。

- カードの左下に、コピー元のアプリの名前が出ます。Android はコピー元を教えてくれないので、コピーしたときにキーボードがつながっていたアプリを出しています。キーボードを一度も出していないアプリでコピーすると、その前のアプリの名前になることがあります
- 「編集」を選ぶと編集の画面が開き、ふつうに打って直せます。「保存」で履歴の文字が書き換わり、元のアプリに戻ります
- ピン留めしていないものは、新しい30件まで残します。設定の「残しておく期間」（期限なし・1時間・1日・1週間・30日）を過ぎたものは自動で消えます。ピン留めしたものは消えません
- パスワードなど、機密の印が付いたコピーは残しません。設定の「コピーの履歴を残す」で切れます
- 画像を直接受け付けない入力欄では、画像をクリップボードに入れて知らせます。入力欄を長押しして貼り付けてください
- 物理キーボードでは Ctrl+Shift+V で開きます。画面キーボードを出していないときも、同じカードの並びがカーソルの近くに出ます。矢印・Tab で選んで Enter（か Space）、またはカードの右下の数字を押して貼り付け、Esc で閉じます。ほかの文字を打つと閉じて、そのまま入力になります。指で触っても画面キーボードのときと同じに使えます
- パネルの下のつまみの真ん中をつまむと動かせ、右下の角（斜線）をつまむと大きさを変えられます。位置と大きさは覚えておき、次に開いたときもそこに出ます。つまみを2回たたくと、カーソルの近く・元の大きさに戻ります
- 開くキーは、設定の「画面キーボード」→「クリップボード」の「物理キーボードで開くキー」で変えられます。ボタンを押してから物理キーボードで組み合わせを押すと、それになります。「使わない」にもできます。Ctrl+Shift+V のままだと、アプリの「書式なしで貼り付け」の代わりにこちらが開きます。Meta+V など、端末が先に取ってしまう組み合わせは効かないことがあります

## 音声入力

録音キー（既定 F12、画面キーボードではマイクのキー）を押している間だけ録音し、離すと端末の中のモデルで文字にして入れます。音声は外へ送りません。

1. マイクを許可します
2. 設定の「音声入力」の一覧から、モデルを「ダウンロード」します（Wi-Fi でなければ、ダウンロードしてよいか確かめます。ダウンロードしている間は、設定画面を開いたままにしてください。もう一度押すとやめ、次は続きからダウンロードします）
3. 使うモデルの「適用」を押します（使っているモデルに「使用中」が付きます）
4. 「見本の音声で測る」で、ダウンロードしたモデルすべての速さと結果を比べられます
5. 録音キーは「録音キー」のボタンで変えられます（一覧から選ぶか、物理キーボードのキーを押します）

録音中はカーソルの近くに「🎤」、認識中は「…」が出ます。無音や雑音だけのときは、何も入れません。

### モデル

話している途中の文字は Nemotron（なければ ReazonSpeech）で出し、入力欄に入る文字は「適用」したモデルで作ります。各モデルには、言語・精度・速さ・句読点・大きさの札が付きます。

| モデル | 大きさ | 札 |
|---|---|---|
| parakeet-ja | 656MB | 日本語・精度 高・速い・句読点あり（NVIDIA の日本語専用） |
| ReazonSpeech | 73MB | 日本語・精度 高・とても速い・句読点なし（途中の表示にも使います。句読点は話して入れます） |
| SenseVoice | 239MB | 中・英・日・韓・精度 中・速い・句読点あり |
| whisper small | 190MB | 多言語・精度 低・遅い・句読点あり |
| kotoba-whisper v2.0 | 538MB | 日本語・精度 高・とても遅い・句読点 少 |
| whisper large-v3-turbo | 574MB | 多言語・精度 高・とても遅い・句読点あり |
| Nemotron-3.5 Streaming | 682MB | 日本語・精度 中・逐次・句読点あり・途中の表示（NVIDIA。落としてあれば途中の文字はこれで出します） |

適用したモデルがダウンロードされていなければ、ダウンロードしてあるほかのモデルを使います（一覧の上にそう出ます）。要らなくなったモデルは「削除」で消せます。話している途中の文字を出すには、Nemotron か ReazonSpeech をダウンロードし、「話しながら文字を出す」をオンにします（既定でオンです）。Nemotron は届いた音声だけを順に文字にするので、長く話しても遅くなりにくく、句読点も付きます。初めて使うときは読み込みに数秒かかり、その間は途中の文字が出ません。

「リストにないモデルを取り込む」で、一覧にないモデルのファイルを選んで足せます。形式はファイル名から見当をつけ、取り込む前に確かめます。

- whisper.cpp（ggml）: ggml-〜.bin のファイル1つ
- sherpa-onnx のトランスデューサ（zipformer など）: encoder・decoder・joiner の .onnx と tokens.txt
- sherpa-onnx の NeMo CTC（parakeet など）: model の .onnx と tokens.txt
- sherpa-onnx の SenseVoice: model の .onnx と tokens.txt

### 聞き続けるモード

録音キー（マイクのキー）を短く押すと、iPhone や Pixel の音声入力のように聞き続けます。話し終わる（0.7 秒ほど黙る）たびに、そこまでを文字にしてカーソルの位置に入れます。

- 聞いている間も、キーボードで打てます。入力中の文字があるときに認識が終わったら、その文字が確定してから入れます
- 話している途中の文字は、入力欄に未確定の文字として出ます（Termux などでは帯に出ます）。キーを押すといったん消え、話している間はまた出ます
- もう一度押すと終わります（話している途中なら、そこまでを入れます）。話さない時間が設定の長さ（はじめは1分）を超えたときや、別の入力欄に移ったとき、「止めて」と言ったときも終わります
- 画面キーボードのマイクのキーは、聞いている間は色が変わります

### 話して入れる記号

「くてん」「とうてん」のように言うと、記号になります（設定の「話して句読点を入れる」で切れます）。言葉の一覧は、設定の「話して入れる記号」で増やしたり減らしたりできます（「既定に戻す」で元の表に戻せます）。

| 言う | 入る |
|---|---|
| くてん／文の終わりの「まる」 | 。 |
| とうてん／文の区切りの「てん」 | 、 |
| かいぎょう・あたらしいぎょう・次の行 | 改行 |
| かいだんらく・次の段落 | 改行2つ |
| はてなマーク・ぎもんふ | ？ |
| びっくりマーク・かんたんふ | ！ |
| かぎかっこ／かぎかっことじ | 「／」 |
| 二重かぎかっこ／二重かぎかっこ閉じ | 『／』 |
| かっこ（かっこ開く）／かっことじ | （／） |
| なかぐろ・三点リーダー・スラッシュ・アットマーク | ・ … ／ ＠ |

- 「まる」「てん」は、文の終わりや区切り（後ろが文の終わり・句読点）で言ったときだけ記号にします。「丸い」「点数」「100点」はそのままです
- 認識が「くてん」を「九点」「点」のように聞き違えたときも、文の切れ目なら句点にします（「です」「ます」の直後の「てん」は句点にします）
- モデルが自分で付けた句読点と重なったら、一つにまとめます。「かっこいい」などのふつうの言葉は、そのままにします

### 声のコマンド

前後に少し（0.6 秒ほど）間を置いて、コマンドだけを言うと、その操作をします（設定の「声のコマンド」で切れます）。文の中で言った同じ言葉は、そのまま文字になります（「メッセージを送信してから寝ます」は文字のまま）。

| 言う | すること |
|---|---|
| 送信して・送って | 送信（送信のボタンがない欄では Enter） |
| 次へ | 次の入力欄へ |
| 取り消して・元に戻して | 直前に音声で入れた文を消す |
| 全部消して・すべて消去 | 入力欄の文字を全部消す |
| 止めて・ストップ | 聞き続けるモードを終える |

- 「送信して」「次へ」「全部消して」「止めて」は、録音の最後に言ったときだけ働きます（取り消せないため）
- 「〜してください」「〜お願いします」と言っても同じです
- 受け取ったコマンドは、カーソルの近くに少し出ます

### 入れたあとに直す

- 音声で入れた直後に Backspace を押すと、入れた文を丸ごと消します（グライドの語と同じ）
- 話している途中に出ていた文字が、入った文と違うときは、候補の窓に両方を出します。途中の文字のほうがよければ、選ぶと入れ替わります
- 音声で入れた文も、選んで Space を押すと再変換できます（辞書の逆引きで読みを付けます。ほかのキーボードで入れた漢字も同じです）

### 録音を捨てる

録音中に Esc を押すか、マイクのキーを押したまま横に払って離すと、録った音声を入れずに捨てます。

### そのほかの設定

- 認識が付ける句読点: 切ると、モデルが自分で付ける「、」「。」を外し、話して入れた句読点だけにします
- 言いよどみを消す: 「えー」「えーと」「あのー」「うーん」などを消します（はじめはオフ）
- ユーザー辞書を音声にも使う: 認識した文で、ユーザー辞書の読みに当たる所を登録した語にします（認識が違う漢字で書いても、読みが同じなら置き換わります。読みが違う書き方をしたときは置き換わりません）
- 聞き続けるモードを終えるまでの無言の時間: 30秒・1分（はじめ）・2分・終えない

## 表示言語

設定の「表示言語」で、Kanade の画面を日本語・英語・端末の言語から選べます（Android 13 以降。端末の設定の「アプリの言語」からも選べます）。

## 設定の書き出しと読み込み

設定の「書き出しと読み込み」で、設定・ユーザー辞書・スニペットを1つのファイル（JSON）に書き出せます。別の端末に移すときや、控えを取っておくときに使います。

- 学習した変換・クリップボードの履歴・キー記録・音声モデルは入りません
- 読み込むと、今の設定・ユーザー辞書・スニペットはファイルの中身に置き換わります。元に戻したいときは、先に今の設定を書き出しておいてください
- 音声入力で取り込んだモデルを「適用」していた場合、移した先の端末にそのモデルがなければ、ある中から使えるモデルを使います

## 入力中の文字を出せないアプリ

Termux のように入力中の文字をうまく出せないアプリでは、入力中の文字を候補の窓に出し、確定したものだけをアプリへ送ります。設定の「入力中の文字を帯に出すアプリ」に、パッケージ名を足せます（既定は `com.termux`）。
