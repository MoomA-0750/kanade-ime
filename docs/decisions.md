## 2026-10-04 Windows 版は「常駐のエンジン＋薄い TSF の DLL」

- TSF の DLL はアプリごとのプロセスに読み込まれるので、そこに JVM や重い推論を入れない。core をそのまま使える。Mozc と同じ形
- 試してやめたこと: すべて DLL の中に書く案、Kotlin/Native で core を DLL にする案
- 右 Alt の単押しは離したときに判定する（TSF 直のアプリでは Alt の押下が届かない）。IMM のアプリでは文字を書いたあとにモードを切り替える
- 根拠: WINDOWS-PLAN.md、64e4973

## 2026-10-14 Windows 版の「あ」「A」はタスクバーの入力の表示に出し、設定の画面は WinUI 3（本人）

- 本人の要望: 常駐のアイコンではなく IME の表示として「あ」「A」と設定へのメニューを出したい。タスクトレイのメニュー（AWT）は文字化けし、画面の作りが古く見えた

- 試してやめたこと: スイッチの「On」を日本語にするのに、アプリの言語の指定（PrimaryLanguageOverride）は、パッケージにしないアプリでは効かなかった。スイッチごとに「オン」「オフ」を書いた
