# DeX で IME に届くキー

段階1の宿題。DeX（Fold 7、One UI 8.5）で物理キーボードのキーが IME まで届くかを表にする。
エミュレータでは DeX の挙動が出ないので、実機で取る。

## 取り方

1. Fold 7 に Kanade を入れ、入力方法で有効にして選ぶ（DeX を起動した状態で）
2. Kanade の設定画面（アプリ一覧の「Kanade の設定」）の「試し打ち」欄に入力の焦点を置く
3. 下の表のキーを1つずつ押す
4. 同じ画面の「キー記録」で「再読み込み」し、届いたキーを確かめる（記録に出ないキーは DeX か One UI が先に取っている）
   - adb がつながるなら `adb shell run-as dev.mooma.kanade cat files/keylog.txt` でも読める
