# 入力データを集める仕組み（本人の要望、2026-11-22）

## 本人の言葉（要旨）
- 「自分に送るバージョン」では、これから、どういう入力があったか・どういうところで追加で変換しているか・どういうタイミングで言語切替をしてどういう単語を打っているか、などのデータを取れるだけ取る仕組みを作ってほしい。ただし重くならないように
- 意図: ① 変換精度を上げるために使えないか ② meltype のような、入力切り替えなしで複数言語を入力できる体験が欲しいので、そのために使えないか

## 決まっていること
- 対象は本人用の版。公開する Release の既定では取らない（設定で入れたときだけ、または本人用のビルドの印で）
- 重くしない: 打鍵の経路で同期して書かない。メモリに溜めて、まとめて別スレッドで書く。上限と古いものの整理を持つ

## 設計で決めること（design-planner へ）
- 何を取るか（候補: 確定した文字列と、その元の読み・打鍵、候補の選び直し・変換のやり直し・zenz が直したところ、日本語⇔英字の切り替えの時刻とその前後の語、アプリの種類、音声入力の結果）。個人の打鍵なので、パスワード欄（macOS の secure input・Android の password フィールド・Windows の password 欄）では取らない仕組みを必ず入れる
- どこに置くか（各 OS の設定のフォルダー。ファイル形式、回転、上限）、本人が中身を見て消せる画面
- 使い道の設計: 変換精度（学習・並べ替え・zenz の確かめ直しへの入力）と、複数言語を切り替えなしで打つ（日本語と英語が混ざる入力の判定）。ここでは「取る形」を先に決め、使い道は次の段階でよい
- 全部の版（Android・Windows・Linux・macOS）で揃える。エンジン（desktop/・core/）に入れるのが基本

## 注意
- 外へ送らない（端末の中だけ）。個人の入力の全文なので、扱いは慎重に（パスワード・認証コードの除外、ログの権限）
- push・Release は本人の確認が要る
